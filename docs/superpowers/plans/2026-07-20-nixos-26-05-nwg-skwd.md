# NixOS 26.05, NWG Lua, and SKWD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the system to NixOS 26.05, make NWG Displays 0.4.3 Lua output persistent, return generated desktop files to runtime ownership, and start SKWD through the graphical session target.

**Architecture:** NixOS/Home Manager move together to release 26.05 while state versions stay 25.11. Application-owned monitor/theme files remain regular files outside Home Manager; tracked Lua loaders consume NWG's generated `monitors.lua` and `workspaces.lua`, with the host layout as fallback. Hyprland imports its environment before activating the systemd graphical session target.

**Tech Stack:** Nix flakes, NixOS 26.05, Home Manager 26.05, Hyprland 0.55 Lua config, nwg-displays 0.4.3, systemd user units, Bash contract tests.

## Global Constraints

- Primary `nixpkgs` input must be `github:NixOS/nixpkgs/nixos-26.05`.
- Home Manager input must be `github:nix-community/home-manager/release-26.05`.
- Every `system.stateVersion` and `home.stateVersion` remains `25.11`.
- Keep `nixpkgs-zen70` pinned to its existing revision.
- Use stock `pkgs.nwg-displays` 0.4.3; no custom package override.
- Linux stays on the 6.12 LTS line for graphical Lenovo profiles.
- Generation 106 remains the known-working NixOS 25.11 rollback.
- Nix/Home Manager must not create, seed, link, or overwrite the generated GTK/icon/NWG outputs named by the specs.
- Preserve unrelated Herdr/Rofi runtime changes in the main checkout.
- Do not force `GTK_THEME`.
- Do not change the working default i915 GuC policy.
